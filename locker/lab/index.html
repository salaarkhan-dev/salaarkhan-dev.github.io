Texture Lab

Every surface, edge, fitting and curve the Evidence Locker is built from, on one page. Sign this off before any feature work — iterating on a swatch sheet is far cheaper than iterating on a finished spread.

Grain is generated with feTurbulence data-URIs rather than bitmap tiles: zero bytes over the wire, seamless via stitchTiles, and each surface dials its own coarseness.

02

The surface recipe

Five layers, always in this order. The third is the one that decides whether this looks like the reference or like a beige rectangle — grain alone never gets there.

1 · Base fill

A flat token colour. Unmistakably a div.

2 · + Fibre grain

Tiled feTurbulence, overlay blend. Texture, but still flat.

3 · + Mottling

Oversized radial stains, multiply. This is the layer that does the work.

4 · + Edge burn

Inset shadow. Aged paper is always darkest at the perimeter.

5 · + Lift

Warm-tinted drop shadow and a sub-degree tilt. Now it's an object.

04

Edges

Straight border-radius reads as digital. The displacement filter is applied to the sheet only, never to a node containing text — otherwise the glyphs wobble too.

clean

Type stays crisp

Machine-trimmed. Cheapest — box-shadow lift.

deckle

Type stays crisp

Hand-made paper. 6px throw, drop-shadow follows the alpha.

torn

Type stays crisp

Ripped. 13px throw, coarser turbulence.

seeded clip-path

No filter at all — a seeded polygon. Cheapest ragged edge.

05

Seeded variation

Six cards, identical markup. Tilt, grain offset and stain placement all derive from hash(id) — so every card differs, and every card is identical on the server and after hydration. Math.random() at render time would mismatch.

09

Motion

Heavy, damped, slightly reluctant. Nothing bounces, nothing is faster than 180ms, hover lifts are ≤4px. All of it collapses under prefers-reduced-motion.
